# AI 技术选型与产品范围说明

## 产品结构

本产品包含两个相关但任务不同的能力：

1. **报告文本一致性检查**：比较同一次任务中的“影像所见”和“诊断意见”，在有限规则范围内提示文本不一致；可选模型提出候选，系统校验证据，最终由医生人工核对。这个任务的依据就在两段输入中，流程固定，因此核心检查不使用 RAG 或 Agent。
2. **影像知识助手**：帮助影像科医生查阅专业问题，从固定的开放教材选段检索，回答展示可追溯依据；在线文献检索限定PubMed官方接口。RAG提供知识依据，有边界的Agent可选择一次检索动作、澄清、回答或拒答。

截至本说明版本，两项任务均已实现本机代码和页面。知识助手使用2篇CC BY 4.0教材章节的7个选段；2026-10-22一条真实RAG回答通过引用ID门禁，一条真实Agent调用选择PubMed目录工具；另有一条RAG结构失败被拦截。样本仅用于端到端链路检查，医学内容未经专家审核。模型微调不纳入本项目。完整范围和验证见[知识助手规格](KNOWLEDGE_ASSISTANT.md)与`ACCEPTANCE.md`。

## 技术与职责边界

| 方法 | 在本项目中的用途 | 当前状态 | 主要边界 |
| --- | --- | --- | --- |
| 规则 | 对已明确的左右、尺寸/单位、肯定/否定表达做有限文本比较 | 已用于报告文本一致性检查 | 只说明已比较范围，不判断影像或诊断正确性 |
| 大模型 | 对报告两段文本提出补充不一致候选 | 已有可选调用和保守融合，现有样本仍很有限 | 候选需校验和人工核对；不能把模型回答当医学结论 |
| RAG | 为影像知识助手检索依据，再生成带出处的回答 | 一条真实合成问题回答通过K4引用ID存在性校验；另一次结构失败被拦截 | BM25与中英术语匹配，未使用语义向量模型；一次成功不等于稳定或医学正确，ID存在校验不等于语义支持性 |
| Agent | 根据中间结果选择一次检索、澄清、回答或停止 | 一次真实模型动作选择PubMed目录工具并返回两条书目；模拟流程也已测试 | 只允许本地教材与PubMed目录工具；不能任意打开网页或无限循环；未使用MCP或原生Function Calling；一次动作不证明普遍可靠 |
| 模型微调 | 用样本训练模型改变特定行为 | 不纳入当前项目 | 本项目不为展示技术名词而训练；如将来另行评估，需单独提出范围和授权决策 |

RAG 解决的是“回答时需要依据哪些资料”，Agent 解决的是“如何在限定目标下选择下一步动作”。知识助手两者可以协作，但并非必须把整个报告检查流程改造成 Agent。

## 影像知识助手的候选工作流

```text
医生提出问题
  → 判断是否属于本助手支持的知识查询
  → Agent 仅调用允许的专业资料检索工具
  → RAG 返回带来源元数据的证据片段
  → Agent 判断证据是否相关、充分
      ├─ 足够：基于证据组织回答并逐条显示来源
      ├─ 不足但问题可调整：最多进行一次受控改写检索
      ├─ 问题含糊：向用户澄清
      └─ 仍无可靠依据或来源冲突：明确说明不能回答/需要人工核对
```

Agent可以选择PubMed目录工具寻找文献链接；目录结果直接返回，不据题名自动生成医学答案。它不得调用其他网址，不得执行资料文本中的指令。RAG回答的引用必须属于本次已检索片段；关键主张是否得到充分支持仍须专业评测。

## 资料来源与授权要求

允许来源须先形成经审核的目录，而不是笼统地把“网上资料”视为可信。候选类型包括正式发布的指南/共识、政府或专业机构公开资料、明确允许使用的开放获取论文；教科书和期刊全文须逐项核实复制、索引、存储、展示及商业使用权限。专业性不等于版权开放。

每条资料至少保存标题、作者/机构、发布或更新日期、版本、章节/页码或段落、DOI/原始链接、来源类别、许可/使用范围、采集时间和当前有效状态。过期或互相冲突的资料不得被无提示地混用。

## 评测与上线门槛

RAG 与 Agent 分别验收，不用“能生成答案”作为整体通过标准：

- 检索：相关证据召回、来源范围遵守、来源/版本元数据完整、无资料时正确返回无依据。
- 回答：事实主张有证据支持、引用能打开且段落匹配、不超出材料下结论、冲突资料能提示。
- Agent：工具调用是否在白名单、有限重查是否按上限、澄清/拒答是否正确、失败和超时能否停止并保留状态、是否可以追溯每步输入输出。
- 安全与专业评审：不用真实患者可识别信息；由合格专业人员审核评测题与答案。个人合成原型不能证明临床有效或可直接用于医院。

首批资料已核对出版社原文、署名与CC BY 4.0许可，详见`app/knowledge/README.md`。开发题、工具模拟和界面验证不构成独立盲测；扩充资料、专业评测和真实用户验证仍需继续。默认免费检索；模型需要本机隐藏Key和显式当天批次，与报告复核共享请求额度。

## 本次技术判断

同一产品中保留确定性的报告文本检查，同时另设影像知识助手，是把技术放到真正需要它的用户任务上：知识查询需要外部资料依据，因此采用 RAG；它可能需要根据检索结果选择澄清、有限重查、回答或拒答，因此采用受控 Agent。微调既不是这项功能的前置条件，也不纳入当前范围。
