## 一分钟了解

输入“影像所见”和“诊断意见”，先运行侧别、单值尺寸、明确肯否三类规则；查看两处原文证据，人工修改后复检，记录反馈并导出。同一会话最多保留12次检查，刷新即清除；检查次数不是独立报告量。

## 运行

本机验收环境为macOS、Python 3.14及Chrome。本项目代码只使用Python标准库，不需要安装模型或下载大文件；当前服务含fcntl本机额度锁，尚未验证Windows，其他Python版本也未逐一验证。

```bash
python3 -m venv .venv
.venv/bin/python app/web_app.py
```

随后访问 http://127.0.0.1:8765 。默认仅免费规则，不读取环境或其他项目的API Key。端口被占用时先核对并关闭自己此前的服务，不要连续启动多个窗口。按Ctrl+C退出。

```bash
cd app
../.venv/bin/python -m unittest discover -s tests
../.venv/bin/python run_acceptance.py
```

旧完整包基线146项Python及32项JS；其后新增5项批次和2项分类兜底方法。本轮只定向运行融合22项、服务23项及接口3项共48项，通过；未重复完整套件，旧全量证据不冒充本轮全量重跑。若已安装Node，可在候选包根目录运行`node --test app/tests/test_review_session.mjs app/tests/test_ux_export.mjs`。冻结36例中34例有AI拟定预期、2例不计分，旧快照保留；正确跳过也可符合草案，不能写成临床准确率。
