# 胸部影像知识选段

首批资料为Springer于2025年2月26日出版的两篇开放获取教材章节，分别是Ann Leung的 *Diagnosis of Focal Lung Disease* 和James F. Gruden、Sharon Steinberger、Daniel B. Green的 *Micronodular Lung Disease*，同属 *Diseases of the Chest, Heart and Vascular System 2025–2028*。

- https://link.springer.com/chapter/10.1007/978-3-031-83872-9_12
- https://link.springer.com/chapter/10.1007/978-3-031-83872-9_13
- 两章文字按CC BY 4.0提供：https://creativecommons.org/licenses/by/4.0/

本项目只摘录少量英文句子，并添加中文AI翻译摘要与检索术语标签。中文摘要未经影像专业人员审阅；图片、表格和完整章节未复制。每段记录保留作者、题名、章节、日期、原始链接、许可及改动说明。检索结果仅代表这7个选段，不能解释为全书或全医学资料覆盖。

`corpus.json`版本和SHA256随每次结果导出，用于复现。若更新资料，先核对来源、许可、发布日期和摘要，再修改版本、补相关评测。语料许可与仓库其他代码的许可状态分别适用。

当前采用BM25与中英术语匹配，无额外向量模型或向量数据库。RAG的生成由可选DeepSeek完成；免费检索只展示资料摘要，不冒充实时模型生成。在线PubMed仅返回文献目录，不把题名或索引收录当成医学结论。
